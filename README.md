# TechLance CRM Platform
### STEM105 – Introduction to Programming | Midterm Project

---

## Project Overview
TechLance is a Customer Relationship Management (CRM) web application inspired by Salesforce. It helps businesses manage contacts, track deals, monitor accounts, assign tasks, and visualize sales performance — all in one platform.

---

## Features
- **Dashboard** – KPI metrics, sales pipeline chart, and activity feed
- **Contacts** – Add, view, and delete customer contacts with status tracking
- **Deals Pipeline** – Kanban-style board with 5 deal stages
- **Accounts** – Company account management with industry and revenue data
- **Tasks** – Create and complete tasks with priority levels
- **Reports** – Bar charts, donut chart, and sales analytics

---

## Technologies Used
- HTML5
- CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript (DOM manipulation, dynamic rendering, local state)

---

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
3. No installation or server required

### Run via GitHub Pages
1. Push this project to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Your app will be live at `https://yourusername.github.io/techlance`
